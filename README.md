# JMComic Next

为 JMComic 打造更清爽的网页体验，融入本地评分、个人偏好管理与 AI 个性化推荐。

## 项目介绍

JMComic Next 基于 [JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python) 提供的接口方案，重构 JMComic 的 WebUI，并围绕浏览、阅读、评价与发现作品完善交互体验。

项目采用 HTML、CSS、JavaScript 前端与 Python 本地服务。浏览器负责页面展示和交互，本地服务负责接口转发、账号配置、数据保存与推荐计算。当前代码自行实现接口调用，无需安装 `jmcomic` Python 包。

## 功能概览

- **清爽的 WebUI**：重新设计首页、分类、搜索、详情与阅读页面，适配桌面和移动端。
- **连续阅读体验**：支持图片分批加载、本地缓存、失败重试与阅读进度记录。
- **本地评分与偏好**：保存 1–10 分总评、评语、标签偏好，以及封面、标题、作者等维度的兴趣反馈。
- **AI 个性化推荐**：结合 Qwen 多模态向量、个人评分与阅读行为，在本地计算推荐排序。
- **可选 LLM 增强**：支持评语偏好提取、画像概述与标题翻译。
- **账号功能整合**：提供收藏、消息、追踪与手动签到入口。

## 数据与发布版本

仓库仅包含源码、界面资源和测试文件。账号密码、API Key、个人评分、收藏快照、阅读记录、用户画像及缓存均不随源码发布；`project/data/` 和 `project/.runtime-cache/` 会在运行时按需创建，并已整目录加入 `.gitignore`。

本地评分和阅读数据保存在自己的电脑上。AI 功能需要远程服务：Qwen 多模态请求会发送封面 URL 和标题，可选 LLM 功能会发送处理所需的相关文本；配置远程 API 后，按实际使用情况可能产生服务费用。

## 本地运行

准备 Python 3.10 或更新版本，并确保系统可以使用 `openssl` 命令（用于部分接口响应解密）。下载并解压项目后，在项目根目录运行：

```bash
python3 local_server.py
```

Python 代码只使用标准库，不需要安装 PyTorch、Transformers、DashScope SDK 或本地模型。智能推荐需要在“账号配置”中填写阿里云百炼 API Key，也可以在启动服务前设置 `DASHSCOPE_API_KEY` 环境变量。

然后访问：

```text
http://127.0.0.1:8000/
```

不要再使用 `python3 -m http.server`，它无法提供账号配置和磁盘缓存接口。

## 浏览器兼容

界面优先适配 Safari 与 iOS Safari 16.4 及以上版本，其次支持 Chromium 105 及以上版本。导航与右侧 Dock 将静态玻璃层和动画控件分层；阅读器控制轨及其菜单改用与搜索框、顶栏按钮同源的普通 CSS 材质，不使用背景模糊或动态位移滤镜，避免 WebKit 在漫画滚动、屏幕旋转与侧栏位移期间发生合成闪烁。同时保留安全区和动态视口适配。移动端表单保持 16px 字号，避免 iPhone 聚焦时自动放大。阅读器在 iOS WebKit 上会使用更保守的图片内存窗口，并以分片 Canvas 还原图片，降低长章节触发标签页重载的概率。

## 账号配置

点击页面右上角的“账号配置”，输入账号和密码。程序会先验证登录，成功后写入：

```text
project/data/account.json
```

该文件以明文保存密码，只应在自己的电脑上使用。服务器默认仅监听 `127.0.0.1`，请不要把监听地址改成局域网或公网地址。账号配置文件已加入 `.gitignore`。

## AI 推荐

推荐主链路是本地、可复现的结构化排序，不再让 LLM 阅读一段纯文字画像后直接猜总分。每本漫画保留封面、标题、作者和标签四类输入；作品评价只使用 1–10 分总评。详情页的五维兴趣反馈和真实阅读行为作为辅助信号，不会被伪装成作品评分。

封面、标题以及封面+标题会分别由百炼 [`qwen3-vl-embedding`](https://help.aliyun.com/zh/model-studio/qwen3-vl-embedding) API 映射到同一个 1024 维向量空间。项目通过百炼专用多模态 HTTP 接口调用模型，不使用 OpenAI 兼容 Embedding 接口，也不需要 Ollama。作者和标签仍使用可审计的离散信号；显式标签硬屏蔽会在排序前过滤。最终只生成一个总推荐分，其中历史总评是主要依据，感兴趣反馈和真实阅读行为提供辅助校正。

推荐会先补齐候选的三类 Qwen 向量，再正式评分；第一次会产生远程 API 调用，之后按封面地址、标题、模型、处理版本和向量维度命中 SQLite 缓存。模型权重和图片不会下载到本地，封面 URL 会随请求发送给百炼处理。

只有保存实际评价、真正开始阅读，或点击生成推荐且遇到未缓存候选时才会调用 Qwen API；仅打开漫画详情、浏览列表和同步收藏不会调用。后台预生成只在已配置百炼 API Key 时运行，没有持久任务队列。

### 配置 Qwen Embedding API

在百炼控制台创建 API Key，然后通过右上角“账号配置”中的“Qwen 多模态 Embedding”保存并测试。若下载的是业务空间配置，还要把 CSV 中的 `dashScope` 地址完整复制到 `DashScope Base URL`；`sk-ws-...` 工作空间 Key 不能发送给默认公共 Host。配置写入：

```text
project/data/qwen_embedding.json
```

也可以不写配置文件，直接使用环境变量：

```bash
DASHSCOPE_API_KEY=sk-... \
DASHSCOPE_API_BASE_URL=https://你的业务空间Host/api/v1 \
python3 local_server.py
```

API Key 只保存在本机且不会通过配置读取接口回传浏览器。`qwen3-vl-embedding` 当前固定使用 1024 维；若以后更换模型或维度，已有向量会因版本不匹配而自动重算。

### LLM 的职责

OpenAI 兼容 LLM 是可选增强，不参与最终打分。它只负责从评语中抽取用户明确说出的标签态度、生成可读的偏好概述，以及按需翻译标题。抽取结果会再次核对漫画 ID、评语和真实标签，只能作为较低置信度的软证据，不能覆盖手工标签反馈，也不能自行产生硬屏蔽。

如需这些增强，在账号配置窗口填写 API Key、Base URL 和模型名称。Base URL 应填写到兼容 API 的版本根路径，例如 `https://example.com/v1`；远程地址必须使用 HTTPS，本机 `localhost` 或 `127.0.0.1` 可以使用 HTTP。没有这项配置时，结构化画像和推荐仍可正常工作。配置写入 `project/data/ai.json`，API Key 不会通过本地 HTTP 接口回传给浏览器。

总评分、评语、逐项标签反馈、同步后的收藏、真实曝光与阅读行为、向量来源记录和推荐反馈保存在 `project/data/user_library.sqlite3`；可读画像快照保存在 `project/data/user_profile.json`。这些文件均已加入 `.gitignore`。实时排序直接从 SQLite 原始证据重建偏好模型，因此新增评价无需等待 LLM 才会生效。

漫画详情页和阅读页都只设置一个 1–10 分总评：1–2 分表示垃圾作品、看了浪费时间，3–4 分表示有严重雷点，5–6 分表示中规中矩，7–8 分表示整体及格且有亮点，9–10 分表示全方面优秀。标签按“未表态、喜欢、软回避、硬屏蔽”循环；总评不会自动传播成对全部标签的喜欢。手工标签偏好的方向取该标签全部当前反馈的平均值，置信度从首次反馈的 0.65 随独立作品样本数递增并在 0.95 饱和；因此一致反馈会逐步增强，但高频标签不会无限放大。硬屏蔽不等待置信度累积，仍会立即过滤候选。

推荐页支持关键字、分类、时间、连载过滤、候选池和最终数量。关键字只用于 JM 初筛，不参与个性化加分。推荐曝光只有在卡片至少 45% 进入视口后才记录；打开详情和开始阅读是不同强度的行为证据。感兴趣与否只在漫画详情页设置，`overall/cover/title/tag_mix/author` 五个维度分别保存一条当前状态；修改同一维度会覆盖旧状态，再次点击已选项会取消并删除该维度的当前状态，不同维度可以同时生效。旧版反馈历史首次迁移时会按漫画和维度归并，同一维度同时存在正负历史时以“感兴趣”为准。只有“整体观感·不感兴趣”会直接增加该漫画的重复惩罚，取消或改选后会同步撤销这条反馈产生的惩罚；其他维度只训练对应特征。近期真实曝光会产生随时间衰减的重复惩罚，而不是永久排除。

可选 LLM 返回的画像补充要求结构化 JSON。程序会尝试本地解析并至多自动整理一次；LLM 失败不会阻止本地推荐。AI 标题翻译开关仍在账号配置窗口中，关闭时继续使用原有翻译接口。

登录成功后，Python 服务会把 AVS 会话保存在当前进程的内存中；切换页面不会重新登录。收藏、消息和追踪等受限请求统一由本地服务转发。如果远端返回 401，本地服务会串行执行一次重新登录并只重试该请求一次，避免多个并发请求重复登录。重启 Python 服务后，首次账号请求会读取配置并重新建立一次会话；会话令牌不会写入磁盘，保存的密码也不会通过本地 HTTP 接口回传给浏览器。

签到只会在点击导航栏“签到”按钮后触发。每次点击会先实时读取当前签到活动 ID，再携带账号 ID 和活动 ID 发送签到请求；签到状态不会读取或写入本地缓存。只有远端明确返回成功状态或“签到成功”消息时才显示成功，并保留“获得多少经验/金币”等奖励信息；空响应、重复签到和无法确认的响应都会显示为失败。同一页面中尚未完成的重复点击只会共用当前进行中的请求，请求结束后可再次点击并重新发送。

阅读器的并发加载数量保存在 `project/data/settings.json`，预设为 1、5、10、20、50、100，也可以输入 1–500 的自定义值。

章节名称优先使用移动 API；多章节作品中名称为空的章节会由本地服务读取 JM 网页详情补全，网页端仍为空时显示“第N话”。单章节作品统一显示“全1话”。网页章节名称在本地缓存 24 小时。

开始阅读后，图片严格按照页码分批从前往后写入 `project/.runtime-cache/images/`，不会因为滚动或页码跳转而插队；当前批次中的某一页下载完成后即可渲染，不需要等待整章。附近解码内容的估算预算在 macOS Safari 中为 160 MB、iOS WebKit 中为 112 MB，其他浏览器为 256 MB；这不是整个标签页的内存上限，单张大图及解码过程仍可能超出预算。远处页面释放图片或 Canvas，但保留等高黑色占位，回看时直接从本地缓存恢复。离开阅读页时，尚未开始的批次会停止，当前解码和待执行布局回调也会释放；从 Safari 前进后退缓存返回时恢复附近页面加载。临时断网或本地服务恢复后，可通过图片上的“重新加载”重新提交预取任务。

## 开发验证

Python 回归检查只使用标准库，后端测试使用临时资料库和缓存目录：

```bash
python3 -m unittest discover -q
```

浏览器逻辑的离线行为检查使用 Node.js 22 及以上版本，无需安装 npm 依赖：

```bash
node --experimental-vm-modules --test test_reader_runtime.mjs test_library_runtime.mjs tests/frontend_ui.test.mjs
```

这些检查覆盖响应正文超时、错误后换线、图片重试和页面恢复、Canvas 释放、消息刷新与分页竞态、账号切换、弹窗滚动锁和提示框清理。网络、浏览器存储与 DOM 由测试替身提供，不调用真实 JM 或 AI 接口；它们不能代替实际 Safari 的渲染检查。

需要在 Safari 检查实际界面时，可启动独立的虚构数据服务：

```bash
python3 tests/serve_ui_fixture.py
```

访问 `http://127.0.0.1:48128/` 可浏览真实页面与组件，左下角有测试标识；`http://127.0.0.1:48128/ui-check.html` 会检查弹窗、滚动恢复和长提示文本，并将结果保存到系统临时目录的 `jmcomic-ui-fixture-report.json`。测试服务不启动真实后端，不提供项目数据目录，也不调用外部接口。它用于界面与交互检查，不能验证真实登录、图片下载或 AI 推荐结果。

## 缓存与清理

接口缓存写入：

```text
project/.runtime-cache/api/
```

漫画原图缓存写入：

```text
project/.runtime-cache/images/
```

缓存规则：

- 相册资料最长缓存 7 天
- 章节资料最长缓存 3 天
- 分类和首页推荐最长缓存 1 天
- API 线路清单缓存 6 小时，失效时会自动重新获取
- 单本收藏状态缓存 30 分钟，收藏状态改变后立即更新
- 单本喜欢状态缓存 30 分钟，喜欢状态改变后立即更新
- 收藏编号快照缓存 6 小时，收藏状态改变后立即更新
- 消息未读数缓存 1 分钟，消息状态改变后立即失效
- 总计最多 1200 项或 64 MB
- 漫画原图最多 10000 项或 2 GB，最长保留 14 天
- 本地服务启动时自动清理过期内容
- 每写入 25 次再次清理
- 超出数量或容量时，优先删除最久未使用的缓存

因此浏览缓存不会无限增长。若要清理网页缓存，可删除整个 `project/.runtime-cache/`；下次启动和访问时会按需重新创建。推荐向量和反馈数据位于 `project/data/user_library.sqlite3`，不在浏览缓存目录中。

## 目录

- `local_server.py`：本地 WebUI、账号配置、推荐 API 与缓存服务
- `local_features.py`：本地证据库、总评分偏好学习和确定性排序器
- `qwen_embeddings.py`：百炼 Qwen 多模态 API、封面/标题/联合向量与缓存命中逻辑
- `project/*.html`：页面入口
- `project/style/`：设计系统和页面样式
- `project/src/api/`：JM API 鉴权、请求与解密
- `project/src/local/`：本地服务客户端
- `project/src/auth/`：本地账号配置与自动登录流程
- `project/data/account.json`：本地账号密码配置
- `project/data/ai.json`：OpenAI 兼容接口配置
- `project/data/qwen_embedding.json`：百炼 Qwen Embedding API Key
- `project/data/user_library.sqlite3`：总评分、评语、标签偏好、交互、收藏、特征来源、推荐历史和反馈
- `project/data/user_profile.json`：最新用户画像
- `project/.runtime-cache/api/`、`images/`：自动管理的接口和漫画原图缓存
