# JMComic Next

为 JMComic 打造更清爽的网页体验，融入本地评分、标签与作者偏好管理。

## 项目介绍

JMComic Next 基于 [JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python) 提供的接口方案，重构 JMComic 的 WebUI，并围绕浏览、阅读、评价与整理作品完善交互体验。

项目采用 HTML、CSS、JavaScript 前端与 Python 本地服务。浏览器负责页面展示和交互，本地服务负责接口转发、账号配置与数据保存。当前代码自行实现接口调用，无需安装 `jmcomic` Python 包。

## 功能概览

- **清爽的 WebUI**：重新设计首页、分类、搜索、详情与阅读页面，适配桌面和移动端。
- **连续阅读体验**：支持浏览器直连图源、附近页面按需加载、失败换线重试与阅读进度记录。
- **本地评分与偏好**：保存 1–10 分总评，自定义标签（喜欢/较喜欢/软回避/不喜欢）与作者（喜欢/不喜欢）偏好，并在卡片和详情页着色。
- **书架整理**：最近阅读、随机历史、稍后再看、我的评分与账号收藏统一保存在本地资料库；搜索框保留最近 50 条搜索记录。
- **可选 AI 标题翻译**：配置 OpenAI 兼容接口后，可用模型翻译作品标题。
- **账号功能整合**：提供收藏、消息、追踪与手动签到入口。

## 数据与发布版本

仓库仅包含源码、界面资源和测试文件。账号密码、API Key、评分、偏好、阅读记录及缓存均不随源码发布；`project/data/` 和 `project/.runtime-cache/` 会在运行时按需创建，并已整目录加入 `.gitignore`。

评分、偏好和阅读数据保存在自己的电脑上。AI 标题翻译需要远程服务，会发送待翻译的标题；配置远程 API 后，按实际使用情况可能产生服务费用。

## 本地运行

准备 Python 3.10 或更新版本，并确保 PATH 中可以使用 `openssl` 命令（账号接口解密需要）。在项目根目录运行：

```bash
python3 local_server.py
```

也可使用 uv 按锁文件创建环境并启动（`.python-version` 选择 Python 3.13）：

```bash
uv sync --locked
uv run --locked python local_server.py
```

访问 `http://127.0.0.1:8000/`，按 `Ctrl+C` 停止。端口被占用时可追加 `--port 8001`。默认仅监听本机，请保持此设置。

项目只使用 Python 标准库，无需前端构建或安装第三方 Python 包。不要使用 `python3 -m http.server`，它无法提供本地 API。Node.js 仅用于开发测试，要求 22 及以上，`.node-version` 选择 24。迁移电脑时不要复制 `.venv`，应重新创建环境。

## 浏览器兼容

V2 前端以现代 iPhone Safari、Mac Safari 和 iPad Safari 为优先目标，保持原生 HTML/CSS/JavaScript，无需构建或安装前端依赖。统一深色主题使用低对比表面、细分隔线与黄色操作强调。

iPhone 竖屏使用顶部菜单入口，导航从左侧滑入并覆盖全屏；搜索、筛选、账号与阅读设置打开底部弹层；iPad 竖屏和手机横屏使用窄侧栏，宽屏使用完整侧栏。阅读页独立布局：返回、标题、目录、页码与图片设置合并在同一个底部工具栏，点击正文切换专注模式；键盘聚焦正文后按空格也可切换，Escape 恢复工具栏。目录、页码跳转和图片设置均可通过弹层操作；键盘 J / K 跳到下一页 / 上一页。

布局使用安全区、动态视口和 VisualViewport 处理浏览器工具栏及软键盘空间，弹层管理背景滚动与焦点；支持减少动态效果和减少透明度偏好。手机导航处于正常页面流中，不固定在视口边缘；阅读页底部面板四周留空，安全区留在面板外侧，避免整条深色背景延伸到 Safari 浏览器栏。移动端不指定固定的浏览器主题色；阅读器面板使用半透明灰色背景，减少透明度模式下保持不透明，不对漫画滚动区域做背景模糊，专注模式完全隐藏工具栏。iOS WebKit 使用更保守的图片内存窗口，并以分片 Canvas 还原图片。WebKit 的尺寸模拟不能替代真机 Safari 的软键盘、安全区和浏览器栏检查。

## 账号配置

在桌面侧栏底部点击账号，或在手机顶部菜单中的账号入口中输入账号和密码；也可从设置页进入。程序会先验证登录，成功后写入：

```text
project/data/account.json
```

该文件以明文保存密码，只应在自己的电脑上使用。服务器默认仅监听 `127.0.0.1`，请不要把监听地址改成局域网或公网地址。账号配置文件已加入 `.gitignore`。

## 评分与偏好

漫画详情页和阅读页底部各有一个 1–10 分总评，点选分数即保存，可清除。参考：1–2 分垃圾作品，3–4 分有严重雷点，5–6 分中规中矩，7–8 分整体及格且有亮点，9–10 分全方面优秀。书架“我的评分”列出全部已评分作品，可按分数筛选。

标签和作者偏好统一在“设置”页编辑，可自由新增、修改名称或分类、删除：

- 标签分四类：喜欢（绿）、较喜欢（蓝）、软回避（橙）、不喜欢（红，带删除线）
- 作者分两类：喜欢（绿）、不喜欢（红）

首页书架卡片、随机作品和详情页按这些设置为标签和作者着色，并在首页显示颜色说明。偏好只用于着色，不会过滤或隐藏作品。评分和偏好保存在 `project/data/user_library.sqlite3`。

## AI 标题翻译（可选）

在“设置 → AI 标题翻译”填写 OpenAI 兼容接口的 API Key、Base URL 和模型名称，并打开“用 AI 翻译标题”后，详情页的“翻译标题”会调用该模型；未开启时使用默认翻译。Base URL 应填写到版本根路径，例如 `https://example.com/v1`；远程地址必须使用 HTTPS，本机 `localhost` 或 `127.0.0.1` 可以使用 HTTP。配置写入 `project/data/translation.json`，API Key 不会通过本地 HTTP 接口回传给浏览器。

登录成功后，Python 服务会把 AVS 会话保存在当前进程的内存中；切换页面不会重新登录。收藏、消息和追踪等受限请求统一由本地服务转发。如果远端返回 401，本地服务会串行执行一次重新登录并只重试该请求一次，避免多个并发请求重复登录。重启 Python 服务后，首次账号请求会读取配置并重新建立一次会话；会话令牌不会写入磁盘，保存的密码也不会通过本地 HTTP 接口回传给浏览器。

签到只会在点击导航栏“签到”按钮后触发。每次点击会先实时读取当前签到活动 ID，再携带账号 ID 和活动 ID 发送签到请求；签到状态不会读取或写入本地缓存。签到请求由本地服务以 `multipart/form-data` 转发（该接口不解析 url-encoded 表单，会空转返回空数组）。远端返回业务成功状态、“签到成功”消息，或真实成功响应那样只含奖励的消息（如 `Jcoin:10 EXP:10`）且没有失败字样时显示成功；“今天已签到”单独提示，不再显示失败。空结果会提示“服务器可能没有收到签到参数”。读取活动失败会说明尚未提交；提交超时、断网、解密失败或响应无法判定时提示“结果未确认”，因为远端可能已经处理成功，不会自动重发。错误提示保留接口原因和状态。同一账号的并发点击共用正在进行的请求，请求结束后可再次点击确认。

阅读器由浏览器直连图源，并发数可选 1、2、5、10、20、50、100，默认 5，仅保存在当前设备的浏览器中。图片线路切换立即重新加载附近页面。

章节名称优先使用移动 API；多章节作品中名称为空的章节会由本地服务读取 JM 网页详情补全，网页端仍为空时显示“第N话”。单章节作品统一显示“全1话”。网页章节名称在本地缓存 24 小时。

正文图片直接从图源进入浏览器，不经过 Python 服务；不再提供服务端图片代理、整章预取或磁盘图片缓存。优先加载当前页及附近页面，离开附近范围会取消加载并释放图片或 Canvas，保留等高占位。每条线路最多等待 15 秒，失败自动切换备用线路；全部失败后可手动重试。不会自动回退到服务器转发。

附近解码内容的估算预算在 macOS Safari 中为 160 MB、iOS WebKit 中为 112 MB，其他浏览器为 256 MB；这不是整个标签页的内存上限。图片分片还原仍在前端完成，GIF 保留动画。离开阅读页停止任务，Safari 前进后退返回后重新加载附近页面。浏览器根据图源响应管理 HTTP 缓存，不承诺离线可用或固定保留时间；不同设备分别下载。

原有 `project/.runtime-cache/images/` 和 `project/data/settings.json` 不再使用，升级不会自动删除旧文件。账号、历史记录、评分与偏好通过 Python 服务处理。

## 开发验证

Python 回归检查只使用标准库，后端测试使用临时资料库和缓存目录：

```bash
uv run --locked python -m unittest discover -q
```

浏览器逻辑的离线行为检查使用 Node.js 22 及以上版本，无需安装 npm 依赖：

```bash
node --experimental-vm-modules --test test_reader_runtime.mjs test_library_runtime.mjs tests/frontend_ui.test.mjs
```

这些检查覆盖响应正文超时、错误后换线、图片重试和页面恢复、Canvas 释放、消息刷新与分页竞态、账号切换、弹窗滚动锁和提示框清理。网络、浏览器存储与 DOM 由测试替身提供，不调用真实 JM 或 AI 接口；它们不能代替实际 Safari 的渲染检查。

需要在 Safari 检查实际界面时，可启动独立的虚构数据服务：

```bash
uv run --locked python tests/serve_ui_fixture.py
```

访问 `http://127.0.0.1:48128/` 可浏览真实页面与组件，左下角有测试标识；任意页面加 `?verify=1` 可运行该页的隔离交互检查，结果保存在浏览器的 `window.__uiReport`；`http://127.0.0.1:48128/ui-check.html` 会检查弹窗、滚动恢复和长提示文本，并将结果保存到系统临时目录的 `jmcomic-ui-fixture-report.json`。测试服务不启动真实后端，不提供项目数据目录，也不调用外部接口。它用于界面与交互检查，不能验证真实登录、图片下载或 AI 翻译。

## 缓存与清理

接口缓存写入：

```text
project/.runtime-cache/api/
```

缓存规则：

- 相册资料最长缓存 7 天
- 章节资料最长缓存 3 天
- 分类和首页推荐最长缓存 1 天
- API 线路清单缓存 6 小时，失效时会自动重新获取
- 单本收藏状态缓存 30 分钟，收藏状态改变后立即更新
- 单本喜欢状态缓存 30 分钟，喜欢状态改变后立即更新
- 收藏编号快照缓存 6 小时，收藏状态改变后立即更新
- 消息未读数缓存 1 分钟，消息状态改变后立即失效
- 总计最多 1200 项或 64 MB
- 本地服务启动时自动清理过期内容
- 每写入 25 次再次清理
- 超出数量或容量时，优先删除最久未使用的缓存

因此浏览缓存不会无限增长。若要清理服务器接口缓存，可删除 `project/.runtime-cache/api/`；下次启动和访问时会按需重新创建。评分、偏好和历史位于 `project/data/user_library.sqlite3`，不在浏览缓存目录中。

## 阅读与随机历史的保存和迁移

最近阅读和随机历史统一保存在 `project/data/user_library.sqlite3`，同一服务的不同浏览器在加载页面时读取同一份记录。历史按作品编号去重、按最后记录时间排序，数据库不再按旧浏览器的 100/200 条上限截断。清空历史会清空服务端对应列表。

打开首页、资料库或阅读页时，会自动将当前网址下的旧浏览器历史合并到数据库；较新的记录优先，导入成功才移除对应旧记录，失败可重试。也可打开 `/history-migration.html` 手动导入并查看数量，该页面不会调用账号或 AI 接口。不同浏览器、域名和端口的旧记录需要分别在原来的地址打开页面导入。

迁移电脑前先完成旧浏览器历史导入，停止服务，再复制完整 `project/data/`。不要复制 `.venv`；在目标电脑重建运行环境。上次阅读章节和图片线路选择仍属于各浏览器自己的设置。
