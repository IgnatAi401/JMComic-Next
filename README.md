# JMComic Next

为 JMComic 打造更清爽的网页体验，融入本地评分、个人偏好管理与 AI 个性化推荐。

## 项目介绍

JMComic Next 基于 [JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python) 提供的接口方案，重构 JMComic 的 WebUI，并围绕浏览、阅读、评价与发现作品完善交互体验。

项目采用 HTML、CSS、JavaScript 前端与 Python 本地服务。浏览器负责页面展示和交互，本地服务负责接口转发、账号配置、数据保存与推荐计算。当前代码自行实现接口调用，无需安装 `jmcomic` Python 包。

## 功能概览

- **清爽的 WebUI**：重新设计首页、分类、搜索、详情与阅读页面，适配桌面和移动端。
- **连续阅读体验**：支持图片分批加载、本地缓存、失败重试与阅读进度记录。
- **本地评分与偏好**：保存 1–10 分总评、评语、标签偏好，以及封面、标题、作者等维度的兴趣反馈。
- **AI 个性化推荐**：结合 Qwen 多模态向量、个人评分与阅读行为，在本地计算推荐排序。
- **可选 LLM 增强**：支持评语偏好提取、画像概述与标题翻译。
- **账号功能整合**：提供收藏、消息、追踪与手动签到入口。

## 数据与发布版本

仓库仅包含源码、界面资源和测试文件。账号密码、API Key、个人评分、收藏快照、阅读记录、用户画像及缓存均不随源码发布；`project/data/` 和 `project/.runtime-cache/` 会在运行时按需创建，并已整目录加入 `.gitignore`。

本地评分和阅读数据保存在自己的电脑上。AI 功能需要远程服务：Qwen 多模态请求会发送封面 URL 和标题，可选 LLM 功能会发送处理所需的相关文本；配置远程 API 后，按实际使用情况可能产生服务费用。

## 本地运行

准备 Python 3.10 或更新版本，并确保系统可以使用 `openssl` 命令（用于部分接口响应解密）。下载并解压项目后，在项目根目录运行：

```bash
python3 local_server.py
```

Python 代码只使用标准库，不需要安装 PyTorch、Transformers、DashScope SDK 或本地模型。智能推荐需要在“账号配置”中填写阿里云百炼 API Key，也可以在启动服务前设置 `DASHSCOPE_API_KEY` 环境变量。

然后访问：

```text
http://127.0.0.1:8000/
```

不要再使用 `python3 -m http.server`，它无法提供账号配置和磁盘缓存接口。

## 浏览器兼容

界面优先适配 Safari 与 iOS Safari 16.4 及以上版本，其次支持 Chromium 105 及以上版本。导航与右侧 Dock 将静态玻璃层和动画控件分层；阅读器控制轨及其菜单改用与搜索框、顶栏按钮同源的普通 CSS 材质，不使用背景模糊或动态位移滤镜，避免 WebKit 在漫画滚动、屏幕旋转与侧栏位移期间发生合成闪烁。同时保留安全区和动态视口适配。移动端表单保持 16px 字号，避免 iPhone 聚焦时自动放大。阅读器在 iOS WebKit 上会使用更保守的图片内存窗口，并以分片 Canvas 还原图片，降低长章节触发标签页重载的概率。

## 账号配置

点击页面右上角的“账号配置”，输入账号和密码。程序会先验证登录，成功后写入：

```text
project/data/account.json
```

该文件以明文保存密码，只应在自己的电脑上使用。服务器默认仅监听 `127.0.0.1`，请不要把监听地址改成局域网或公网地址。账号配置文件已加入 `.gitignore`。

## AI 推荐

推荐主链路是本地、可复现的结构化排序，不再让 LLM 阅读一段纯文字画像后直接猜总分。每本漫画保留封面、标题、作者和标签四类输入；作品评价只使用 1–10 分总评。详情页的五维兴趣反馈和真实阅读行为作为辅助信号，不会被伪装成作品评分。

封面、标题以及封面+标题会分别由百炼 [`qwen3-vl-embedding`](https://help.aliyun.com/zh/model-studio/qwen3-vl-embedding) API 映射到同一个 1024 维向量空间。项目通过百炼专用多模态 HTTP 接口调用模型。作者和标签仍使用可审计的离散信号；显式标签硬屏蔽会在排序前过滤。最终只生成一个总推荐分，其中历史总评是主要依据，感兴趣反馈和真实阅读行为提供辅助校正。

推荐会先补齐候选的三类向量，再正式评分；第一次会产生远程 API 调用，之后按封面地址、标题、模型、处理版本和向量维度命中 SQLite 缓存。模型权重和图片不会下载到本地，封面 URL 会随请求发送给百炼处理。

只有保存实际评价、真正开始阅读，或点击生成推荐且遇到未缓存候选时才会调用 Qwen API；仅打开漫画详情、浏览列表和同步收藏不会调用。后台预生成只在已配置百炼 API Key 时运行，没有持久任务队列。

## 缓存与清理

接口缓存写入：

```text
project/.runtime-cache/api/
```

漫画原图缓存写入：

```text
project/.runtime-cache/images/
```

缓存规则：

- 相册资料最长缓存 7 天
- 章节资料最长缓存 3 天
- 分类和首页推荐最长缓存 1 天
- API 线路清单缓存 6 小时，失效时会自动重新获取
- 单本收藏状态缓存 30 分钟，收藏状态改变后立即更新
- 单本喜欢状态缓存 30 分钟，喜欢状态改变后立即更新
- 收藏编号快照缓存 6 小时，收藏状态改变后立即更新
- 消息未读数缓存 1 分钟，消息状态改变后立即失效
- 总计最多 1200 项或 64 MB
- 漫画原图最多 10000 项或 2 GB，最长保留 14 天
- 本地服务启动时自动清理过期内容
- 每写入 25 次再次清理
- 超出数量或容量时，优先删除最久未使用的缓存

因此浏览缓存不会无限增长。若要清理网页缓存，可删除整个 `project/.runtime-cache/`；下次启动和访问时会按需重新创建。推荐向量和反馈数据位于 `project/data/user_library.sqlite3`，不在浏览缓存目录中。
